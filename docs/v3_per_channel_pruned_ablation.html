IV. Variant (iii) — drop masked channels only

A more conservative cut: keep all 320 features from active channels, drop only the 30 always-zero features from _TRAINING_CONSTANT_CHANNELS = {17, 18, 19} (the 5-minute features that are masked at training and emit zeros). Hypothesis: zero-variance columns should be inert by construction.

Result: bit-for-bit identical to baseline across every fold. Every AUC matches to four decimals — not "within noise band," literally identical. Confirms that XGBoost's split-gain calculation correctly treats zero-variance columns as inert: a column where all values are zero has only one possible histogram bin and cannot improve any split.

Variant (iii) is a provably lossless cleanup: predictions from the trained booster are unchanged because the masked features could never have entered a split. The next section assesses this claim rigorously across multiple seeds.

N=1 beats N=5. A single feature — ch4_pct_rank (RSI(14) percentile rank within a 60-bar window) — produces AUC 0.5093 with std 0.0006 (the lowest in the entire sweep). Higher than N=5 (0.5074), higher than N=30 (0.5100), higher than baseline N=350 (0.5082).

The honest picture:

  • The v3 model's entire edge is one feature. Everything else either reproduces the same signal or adds noise the booster overfits to.
  • N=3 is the WORST configuration in the whole sweep at 0.5056. Adding 2 features to the single best one hurts AUC by 0.0037.
  • The std=0.0006 at N=1 means the result is highly stable across seeds. The multi-feature configurations have higher seed variance precisely because they overfit to seed-dependent spurious patterns.
The v3 model's edge reduces to: overbought/oversold conditions have slight mean-reversion bias on a 4-bar forward horizon. That's the entire signal — what 350 features and 28 channels worth of engineering buys you over the simple RSI-pct-rank lookup.

X. Final synthesis (post-pivot)

The loop ran five iterations: drop-masked proof, gain-prune assessment, top-N sweep, sub-5 sweep, v4.5 comparison, and (the pivot) N=1 booster inspection. The N=1 inspection revealed that the "one-feature edge" interpretation was wrong, leading to a revised synthesis:

  1. v3 pruning is structurally safe. Drop-masked is provably bit-exact lossless; drop-all-zero-gain is statistically lossless (+0.0003 ± 0.0016 across 5 seeds). This finding stands.
  2. v3's "edge" is overfitting noise, not signal. The N=1 booster's implied curve is non-monotonic (Pearson r = −0.10 with the input). AUC 0.5093 ± 0.0006 reflects 118 noise-pattern thresholds that rank slightly better than random — not a clean mean-reversion phenomenon.
  3. v3's AUC ceiling at ~0.51 is the no-signal floor. All N values from 1 to 350 land in 0.508–0.510. The model can't find more signal because there isn't any.
  4. v4.5 takes the opposite architectural bet (89% of features active, diffuse gain) and lands at the same ceiling. Two opposite design philosophies, same effective AUC — the cleanest evidence yet that the bottleneck is not feature engineering.

Operationally:

  • v3 inference can be radically simplified. Top-30 by gain matches baseline; the proposal in proposal-v3-feature-pruning.md is ship-ready. Latency win is real; AUC win is illusion.
  • Don't ship N=1. It "wins" on OOF AUC by 0.001 only because it has less overfitting surface. The mechanism is degenerate. Top-30 is the right shipping target.
  • Don't expect feature engineering to lift v3 or v4.5. The ceiling is structural, not transformational.
  • Pursue bar-structure (dollar bars, event-clock samples, triple-barrier labels) as the actual mechanism. Or accept the fee tier as the deployment-blocker and look at pro-tier strategy economics.
The loop closed the question. v3's effective AUC is at the no-signal floor; v4.5's is at the same floor through a different path. Feature engineering, pruning, regularization, and tier-weighting have all been fully extracted. The next AUC improvement, if there is one, doesn't live in the feature column at all.

XI. The pivot — N=1 booster is degenerate

The Section VIII finding (N=1 wins) was banked on "RSI pct_rank captures the mean-reversion edge." This inspection trained the N=1 booster on full data and asked: what function does it actually learn?

Pearson r(pct_rank, P(up)) = −0.10 — essentially uncorrelated. The booster trained 200 trees, 1740 split nodes, 118 unique thresholds on one input. That's a complex piecewise-constant function fitting nothing meaningful.

The 0.9-percentage-point lift of N=1 over N=5 isn't because RSI pct_rank is a strong signal. It's because with one input dimension, the booster has less surface area to overfit to, so the overfit penalty on OOF AUC is smaller. The signal extracted is fundamentally noise-pattern fitting, just less of it than with more features.

Implication for the proposal: ship top-30 by gain (the sweep's empirical peak with a defensible signal-to-overfit ratio), not N=1. The latency savings still hold either way.
